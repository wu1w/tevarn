FEATURES / 核心特性

一台机器，一整支 AI 团队

从雇佣 AI 员工到权限治理，从用量账本到技能自生长 —— Tevarn 把 AIOS 的每一层都做成了可运行的真实系统。

01

AI 员工 Crew

在本机雇佣并调度 AI 员工，带预算、授权与记忆总线，像管理一支真实团队。

02

统一 Run 模型

chat / inbox / cron 共享一套运行模型，支持检查点恢复，任务中断也能接续。

03

权限法院

一条决策路径，layer / rule / verdict 三级权限治理，Kernel 页可视化全程。

04

用量与缓存账本

真实 token / billable / prompt-cache 指标，非 mock —— 每一分消耗都有据可查。

05

技能自动生成

Agent 遇到新任务类型会自动编写新工具：17 个内置技能 + 无限扩展空间。

06

OS 级能力

文件读写、终端命令、浏览器控制、SQLite 查询 —— 全部经三级权限模型校验。

07

智能编排

简单问题单 Agent 直答；复杂任务可选并行草稿扇出 + 汇总（默认关闭）。

08

双端联动

Windows PC 工作站 + 安卓手机端远程遥控，离开工位也能调度你的 Crew。

PERMISSION COURT

权限法院：
每一次操作，都要过堂

AI 能做事，更要守规矩。Tevarn 把所有 OS 级能力收敛进一条决策路径，三级权限治理让每一步都可审计、可拦截、可回放。

  • 一条决策路径 —— 文件、终端、浏览器、数据库，统一走同一道门
  • 三级治理 —— layer / rule / verdict 层层校验，权责清晰
  • Kernel 页可视化 —— 判决过程实时可见，不是黑盒
L1

LAYER · 层级判定

request enters layer pipeline

▼
R2

RULE · 规则匹配

matched against policy rules

▼
V3

VERDICT · 判决执行

allow / deny, fully logged

layer=os  rule=workspace-only
verdict: ALLOW · logged to kernel
