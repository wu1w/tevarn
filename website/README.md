# Tevarn 官网落地页

**冷白机身 · Light Console** 风格的产品官网单页。

## 品牌色

- 电光紫 `#6D5DF6` / `#8B7CFF`
- 霓虹青 `#00A8C0` / `#22D8EE`

## 本地预览

```bash
npx --yes serve website -p 5173
# 浏览器打开 http://127.0.0.1:5173
```

## 文件

| 路径 | 说明 |
|------|------|
| `index.html` | 完整单页（内联样式与交互） |
| `assets/logo.png` | 品牌 Logo |
