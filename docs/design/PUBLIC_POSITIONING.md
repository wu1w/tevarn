# 公开定位（半页）

**一句话**

> Takton 是**带治理内核的可自进化数字员工运行时**（本地优先）——不是又一个 coding CLI / chat wrapper。

**三根柱子**

1. **统一 Run**：chat / inbox / cron / cluster 同一执行记录，可恢复  
2. **权限一张网**：permission_court 可解释 allow/deny  
3. **可信自进化**：技能回放验证后才能上岗  

**默认轻**

SQLite · 无 Redis · 无 Qdrant 即可跑；可选加速。

**版本（feature）**

`0.4.10-alpha`
