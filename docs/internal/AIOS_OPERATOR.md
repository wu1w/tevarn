# AIOS 操作手册（内部 · 0.6 内测）

面向主人自己用一周，**不需要看代码**。

## 日常路径（企业 IM）

1. **侧栏点同事** → 一人一会话（CEO=小白 / 工程师…）
2. **点头像** → 资料卡：能力开关、停职、今日任务
3. **对 CEO 说话** → 派活 / 招人 / 建项目组  
   - 例：「组织工程师巡检内核，建项目组」
4. **侧栏项目组** → 看各人进度，点开结果
5. **审批** → 只处理「员工扩权」和「进化提案」  
   - 不是每一次 shell/glob 弹窗

## 工单生命周期

```
pending → claimed → done
                 ↘ fail 重试 → dead（死信台：重放/丢弃）
```

- 杀后端：pending 仍在 SQLite；claimed 超时会 reclaim
- 死信：员工页「死信台」
- 在跑：内核页「现在在跑」

## 权限分层

| 谁 | 工具调用 | 主人要批吗 |
|----|----------|------------|
| 员工工单 | 编制 capabilities | 否 |
| 主人↔CEO 对话 | 可弹危险确认 | 可 |
| 扩权 / 进化 | 审批中心 | **是** |

## 记忆

- 员工记得什么 → 资料卡「记忆」= Identity Memory（权威）
- 不要再加第五套记忆系统（见 MEMORY_AUTHORITY.md）

## 一周自检清单

- [ ] Day1：招 1 人、派 1 单、看到 done
- [ ] Day2：多员工项目组进度可读
- [ ] Day3：kill 后端后工单可恢复
- [ ] Day4：死信重放成功
- [ ] Day5：扩权审批一次
- [ ] Day6：进化提案批/拒/回滚
- [ ] Day7：日报/通知有感，无数据丢失

## 备份

- 内核页右上角 **一键备份** → 下载 JSON（编制 / 记忆 / 工单 / 会话摘要 / 审计尾）
- 不含 API 密钥明文；大库条目有截断
- 盘挂前建议每周导出一次

## 配置

- `TAKTON_AIOS_PROFILE=aios-dev`
- 默认 SQLite；Redis 可选（STORAGE.md）
- 模板员工：`python -m backend.scripts.seed_template_crew`
